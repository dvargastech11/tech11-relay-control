Push Firmware Update

Uploads a compiled .bin (Arduino IDE: Sketch → Export Compiled Binary) and pushes it directly to the selected device over the network. The device reboots automatically on success.

Warning: pushing the wrong .bin (or one built for a different board) can leave the device unable to boot. Double-check the file before pushing to hardware controlling live relays.
