External API - Elevator Activation

Lets an external system trigger a relay by naming the Building, Elevator, and Floor - no need to know internal MAC addresses, IPs, or raw relay numbers.

Request Format

POST to /api/activate with header X-API-Key: <your key> and a JSON body:

{
  "building": "South Tower",
  "elevator": "1",
  "floor": "5"
}

Example using curl:

curl -X POST http://<server>:5000/api/activate \
  -H "X-API-Key: {{ api_key or '' }}" \
  -H "Content-Type: application/json" \
  -d '{"building": "South Tower", "elevator": "1", "floor": "5"}'
